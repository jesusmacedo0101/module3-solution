# Coursera — Module 3 Coding Assignment

This is the **required graded** solution for the Johns Hopkins University HTML, CSS, and Javascript for Web Developers Module 3 assignment.

## Contents
- `index.html`: single-page HTML solution.
- `css/bootstrap.min.css`: Bootstrap **3.4.1** (local dependency).
- `css/styles.css`: external custom CSS.
- `js/jquery.min.js`: jQuery **3.7.1** (local dependency).
- `js/bootstrap.min.js`: Bootstrap **3.4.1** collapse JavaScript (local dependency).

All files work locally and on GitHub Pages without a CDN.

## Test
1. Open `index.html` in a browser.
2. At **desktop/tablet width (>=768px)**, verify the Food, LLC navbar has no visible menu button or links.
3. At **mobile width (<768px)**, click the hamburger button; Chicken, Beef and Sushi should appear and the menu should expand/collapse.
4. Verify the header scrolls away, Our Menu is centered, and the gray Chicken section extends down the page.

The three mobile labels point to the one required Chicken content block because the optional three-section enhancement is not included in this graded version.

## Publishing
Upload the `module3-solution` folder to a GitHub repository. Enable Pages in repository Settings → Pages, using the deployment branch (typically `main`) and `/ (root)`. The assignment URL will look like `https://YOUR-USERNAME.github.io/YOUR-REPO/module3-solution/` when the folder is placed at the repository root. Submit your **actual** Pages URL to Coursera for peer review.
